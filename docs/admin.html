更新手順

  1. Google Sheetsを編集する。
  2. ローカルでSupabaseの環境変数を設定する。
  3. 追加・修正だけなら通常インポート、削除も反映するなら完全再インポートを実行する。
  4. 反映後、このページで件数と最新日付を確認する。

通常インポート

$env:SUPABASE_URL="https://ptlbobhebwjaebrdgvpl.supabase.co"
$env:SUPABASE_SECRET_KEY="sb_secret_..."
python tools\import_supabase.py

完全再インポート

$env:SUPABASE_URL="https://ptlbobhebwjaebrdgvpl.supabase.co"
$env:SUPABASE_SECRET_KEY="sb_secret_..."
python tools\import_supabase.py --reset

Secret keyはこのページやGitHubには保存しません。CloudflareではVariables and SecretsにSecretとして保存します。
