# プレイヤー挙動チェックリスト

main.js リファクタリング(プレイヤー抽出)前後で不変であるべき挙動の一覧。
「自動」列は `tests/e2e/player.spec.mjs` でのカバー状況。未カバー項目は
リリース前に手動確認するか、フェーズを進める中で自動化する。

| # | シナリオ | 期待挙動 | 自動 |
|---|---------|---------|------|
| 1 | ビューワーで再生 → 戻る → ミニプレイヤー → 復帰 | 同一プレイヤーを引き継ぎ、再生位置維持・リロードなし | ✅ |
| 2 | ドック中に同じ動画を再度開く | 復帰のみ(再生成なし) | ✅ |
| 3 | ドック中に別の動画を開く | 旧プレイヤーのみ破棄、新規生成 | ✅ |
| 4 | ミニプレイヤーの✕で閉じる | プレイヤー破棄、ビューワーも閉じる | ✅ |
| 5 | 開閉の繰り返し | プレイヤー/iframe/タイマーがリークしない | ✅(iframe/インスタンス数のみ) |
| 6 | ビューワー → 全画面 → Esc | 埋め込みに戻るだけ(破棄・ミニ化しない)、再度Escでミニ化 | ✅ |
| 7 | ビューワー ⇔ 音楽バー(「音楽プレイヤーで聴く」) | 同一プレイヤーを引き継ぎ、API準備前の移譲でも二重生成しない | ✅ |
| 8 | Esc キーで閉じる | #1 と同じミニ化挙動 | ✅(#6に含む) |
| 9 | キュー(マイリスト連続再生)のENDED遷移 | 次アイテムへ遷移し旧プレイヤーのみ破棄 | ✅(前後移動・リピートは手動 — 2026/07/19 実YT環境で確認済み) |
| 10 | `?v=&t=&ch=` 付き URL で直接開く | 該当動画・位置で復元、完全クローズでURLから消える | ✅(戻る/進むは手動 — 既知の未restore) |
| 11 | モバイル幅(≤700px)での再生操作 | 埋め込まず YouTube 外部表示(t=引き継ぎ) | ✅ |
| 12 | 音量変更の永続化(localStorage kanaVol) | ビューワー/ミニ間で音量共有 | ⬜ 手動 — 2026/07/19 実YT環境で確認済み(※ミニ→ビューワー復帰時にスライダー表示が旧値のまま残るのはリファクタ前と同一の既存挙動。実音量は共有される) |
| 13 | YT エラー時のフォールバック | 壊れたプレイヤーを破棄し fallback iframe へ | ✅ |

## 手動確認の手順

```bash
npm run build          # 現在のソースから docs/dist を生成
node scripts/serve-docs.mjs
# → http://localhost:4173 で上記シナリオを確認
```

## 自動テストの実行

```bash
npm run e2e            # 既存の docs/dist に対して実行
npm run e2e:build      # ビルドしてから実行(リファクタ検証時はこちら)
```
